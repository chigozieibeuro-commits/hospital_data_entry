Hospital Appointment API

A simple backend API built with FastAPI that allows patients to book hospital appointments. Patient details and appointment dates are stored in a PostgreSQL database.

Technologies Used

- Python
- FastAPI
- PostgreSQL
- Docker

Features

- Register hospital appointments.
- Accept appointment dates through the API.
- Store patient and appointment details in PostgreSQL.
- Validate input data using Pydantic.
- Test API endpoints using Swagger UI.

How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Configure the PostgreSQL database connection.
4. Build and start the application using Docker.

API Documentation

After starting the API, visit:

"http://127.0.0.1:8000/docs"

Use Swagger UI to test the available endpoints and submit appointment details, including the appointment date.

Database

PostgreSQL stores the submitted patient information and appointment dates for future retrieval.
